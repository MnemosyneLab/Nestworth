# v0.1.5 Phase 0 Goldens

These synthetic vectors freeze the deterministic inputs and outputs required by the v0.1.5 phases. They contain no personal data, selected paths, credentials, provider payloads, or real financial records.

The relational schema-4 fixture is src-tauri/test-fixtures/v0.1.4.sql. It preserves the v0.1.3 history fixture and adds two active cost-basis declarations plus one revocation declaration.

## Recurrence dates

Schedule arithmetic is performed on local CalendarDate values in the confirmed History Origin timezone. The anchor is immutable, and monthly or yearly occurrences clamp to the last valid target-month day.

| Rule | Input | Expected dates |
| --- | --- | --- |
| Daily, every 2 days | 2026-01-30 through 2026-02-05 | 2026-01-30, 2026-02-01, 2026-02-03, 2026-02-05 |
| Weekly, every 2 weeks | 2026-01-30 through 2026-02-20 | 2026-01-30, 2026-02-13 |
| Monthly, every 1 month | 2026-01-31 through 2026-04-30 | 2026-01-31, 2026-02-28, 2026-03-31, 2026-04-30 |
| Monthly, every 1 month | 2028-01-31 through 2028-03-31 | 2028-01-31, 2028-02-29, 2028-03-31 |
| Yearly, every 1 year | 2028-02-29 through 2032-02-29 | 2028-02-29, 2029-02-28, 2030-02-28, 2031-02-28, 2032-02-29 |

Additional locked cases:

- An end date of 2026-02-15 for the monthly 2026-01-31 rule yields 2026-01-31 only.
- Valid intervals are daily 1..365, weekly 1..52, monthly 1..24, and yearly 1..10. Zero and values above those bounds are invalid.
- America/New_York DST transitions do not change a local-date sequence and no UTC time is derived for an occurrence.
- Generation is capped at 366 unique occurrences and reports has_more when continuation exists.

## Backup manifest and archive boundary

The minimal valid archive has exactly these two regular entries in logical order:

    manifest.json
    database.sqlite3

manifest.json is UTF-8 JSON without a trailing newline and uses the following stable property order:

    {"formatId":"com.nestworth.backup","formatVersion":"1","backupId":"01a0188f-9100-7000-8000-000000000001","productVersion":"0.1.5","databaseMigrationVersion":5,"createdAt":"2026-08-20T00:00:00.000Z","householdId":"11111111-1111-4111-8111-111111111111","householdName":"Fixture Household","databaseByteLength":16,"databaseSha256":"3f8434aff012ffcb594ad7527d6042841ce94f499887f86ab828f84a9a275f91"}

The database vector is the 16-byte ASCII text SQLite format 3 followed by one NUL byte. Its SHA-256 is 3f8434aff012ffcb594ad7527d6042841ce94f499887f86ab828f84a9a275f91.

Reject archives with extra entries, directories, symlinks, encrypted entries, absolute or traversal paths, a size mismatch, or a checksum mismatch. Selected paths never enter the manifest or any DTO.

## Benchmark comparison

Use base currency CNY and price-return benchmark observations:

| Date | Benchmark level |
| --- | ---: |
| 2026-01-02 | 100 |
| 2026-01-04 | 103 |

For a portfolio whose linked daily TWR is 1.0404 over the same inclusive endpoint interval, the benchmark return is 0.03, excess return is 0.0104, and the display value is 1.04 percentage points.

Benchmark comparison is unavailable when either endpoint observation is missing or outside the inclusive closed-day carry window. Portfolio TWR remains visible. A foreign benchmark level is carried in its native currency; endpoint FX is selected independently at the closed-day cutoff.

## Search ordering

Search trims the query and accepts 2..100 Unicode scalar values. Total results are capped at 1..50, with a per-type cap of 10. Ranking is exact, then prefix, then substring, then type priority, then stable label, then typed ID.

Type priority is Account, Instrument, Institution, Group, Member, Activity.

Fixture query broker returns:

1. Account Brokerage, ID 99999999-9999-4999-8999-999999999999, by prefix.
2. Institution Active Broker, ID 66666666-6666-4666-8666-666666666666, by substring.

Fixture query fix returns Instruments in stable label order:

1. Fixture ES3 — 21212121-2121-4212-8212-212121212121
2. Fixture Index — 24242424-2424-4424-8424-242424242424
3. Fixture QQQ — 20202020-2020-4202-8202-202020202020
4. Fixture VOO — 25252525-2525-4252-8252-252525252525
5. Fixture XLF — 27272727-2727-4272-8272-272727272727
6. Fixture ZERO — 26262626-2626-4262-8262-262626262626

An exact QQQ query returns one Instrument. Archived records are excluded unless include_archived is true; query ARCH therefore returns no result by default and the archived Instrument 23232323-2323-4323-8323-232323232323 when enabled. Search never returns amounts, raw legs, media bytes, or records from another Household.
