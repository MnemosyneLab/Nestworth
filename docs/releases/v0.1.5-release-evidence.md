## Distribution policy and remaining external gates

The local artifact is ad hoc signed with no Team ID. `security find-identity -v -p codesigning` found zero valid signing identities. It is therefore a controlled-test artifact only; it is not Developer ID signed, notarized, stapled, or suitable for public distribution. `spctl` acceptance is intentionally not claimed.

The following require release-owner or device-side action before publication:

- release PR approval and green CI or named clean-machine equivalent evidence;
- keyboard-only and device VoiceOver smoke testing across the new routes and dialogs;
- Developer ID signing, notarization, and ticket stapling under the chosen distribution policy;
- exact artifact retention in the release system, changelog date finalization, annotated tag creation, and any GitHub release publication.

Until those gates are completed, v0.1.5 remains `Unreleased` and no public artifact is claimed.
